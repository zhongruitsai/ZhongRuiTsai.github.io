How to use real Yahoo Finance CSV data (offline method)
=======================================================
1. Go to https://finance.yahoo.com/quote/AAPL/history/
2. Set date range to 2022-01-01 ~ 2024-12-31
3. Click "Download" to save the CSV
4. Rename and place the file here:
     data/AAPL.csv
     data/MSFT.csv
     data/NVDA.csv
     data/TSLA.csv
     data/SPY.csv

The script will automatically detect and use these files
over the built-in approximate data.
